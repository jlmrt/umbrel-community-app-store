# JLMRT Umbrel Community App Store

> [!WARNING]
> Apps in this community store may be experimental. Review each app's warning and release notes before installation, and do not use pre-release builds with irreplaceable data.

This repository contains Umbrel package manifests for JLMRT applications. Application source code and container images are maintained separately.

Add this community store to umbrelOS using:

```text
https://github.com/jlmrt/umbrel-community-app-store
```
